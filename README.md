# Android Vacation Planner

An Android application for planning and organizing vacations, managing excursions, and keeping track of important travel dates!

## Features

- **Vacation Management:** Create, view, edit, and delete vacation records.
- **Excursion Management:** Associate excursions with vacations and manage their details.
- **Data Validation:** Validate user input and enforce date constraints to maintain data integrity.
- **Date Alerts:** Configure alerts for important vacation dates.
- **Vacation Sharing:** Share vacation details through Android's available sharing options.
- **Local Data Persistence:** Store vacation and excursion records using Room and SQLite.
- **User Interface:** Navigate a polished, multi-screen interface designed for managing travel plans.

## Overview

The Android Vacation Planner is a mobile application developed in Java using Android Studio. It provides users with a centralized place to create and manage vacations, organize associated excursions, and receive alerts for important travel dates.

Built with Room persistence over SQLite, the application stores vacation and excursion data locally on the device. The project was developed, tested, and packaged as a signed APK.
